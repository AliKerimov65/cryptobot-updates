# cryptobot-updates

Канал автообновления приложения CryptoBot (com.cryptobot.app), R209.

## Протокол

1. Приложение читает манифест:
   `https://raw.githubusercontent.com/AliKerimov65/cryptobot-updates/main/version.json`
2. Если `versionCode` манифеста больше установленного — показывается баннер.
3. APK скачивается из `apkUrl` (поддерживается прямой бинарник и `.b64` —
   base64-обёртка, детект по расширению URL).
4. Клиент проверяет SHA-256 финальных байт APK против поля `sha256`.
   Несовпадение = файл удаляется, установка не предлагается.
5. Установка — системным установщиком Android поверх текущей версии;
   подпись контролирует ОС (сертификат SHA-256
   `c36825fa1ce13c03d119ec5234cb5f051a1d4a83c1c6afcaffc3ac5a706abe14`).

## Поля манифеста

- `versionCode` (int, обяз.), `versionName` (строка)
- `apkUrl` (обяз.) — прямая HTTPS-ссылка на APK или .b64
- `sha256` — хэш финальных байт APK (после раскодирования .b64)
- `notes` — краткое описание релиза (показывается в баннере)
- `minVersionCode` — минимальная версия, с которой обновление допустимо
- `publishedAt` — дата публикации (YYYY-MM-DD)
